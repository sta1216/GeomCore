# M3b-1 曲面求交（SSI）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `geom/brep` 增加曲面-曲面求交：对 Plane/Cylinder/Cone/Sphere/Torus/NURBS 补丁对输出有序、残差受 `tol` 约束的交线折线，相切/重合等退化输入返回可诊断失败；附带 QA-9 语料与基准。

**Architecture:** 自适应三角化补丁 → 三角-三角求交生成种子线段 → 四参数 Newton（3 方程、沿零空间步进）精化 → 预测-校正追踪 → 端点合并与闭合检测。参数域按曲面周期（`2π`）归一化；只用精确谓词做三角形退化分类，其余判定带显式容差。切线/重合不猜：返回 `SsiIssue` 诊断码。

**Tech Stack:** C++20、header-only、现有 `SurfaceGeometry` 变体、doctest、CMake/MSVC `/W4 /WX /utf-8`。无新依赖。

**Spec:** `docs/architecture/geometry-library-architecture.md`（§4.7、§8.6、§12.7、§16.2 M3、§16.3）与 ADR-015（不做全局精确有理 SSI）。

## Global Constraints

- C++20；公开头文件 `#pragma once`、`namespace geom { inline namespace v1 {`、全部 `inline`/模板，不引入 doctest。
- 不使用新的第三方依赖；不使用全局 epsilon；容差只能来自 `SsiOptions::tolerance` 或显式常量。
- 错误用 `Result<T>` + `Errc`（现有值：`non_finite`、`degenerate`、`tolerance_violation`、`numeric_failure`、`unsupported`、`index_out_of_range`）。
- 所有测试注册进 `tests/CMakeLists.txt` 的 `GEOM_TEST_SOURCES`；每个测试文件自带所需头文件。
- 同一输入必须确定性：不得依赖指针、哈希遍历顺序或未初始化内存。
- 公开 API 的每个前置条件写在头注释；debug 构建用 `assert` 固化，release 不得静默产生非法结果。
- 每个任务先写失败测试（RED 证据），再最小实现，Debug 与 Release 全绿后单 commit。
- 不承诺精确有理交线；输出折线每段残差 ≤ `tolerance`，端点一致。

## 范围与拆分（需评审确认）

M3 在架构中含 SSI、曲面布尔、healing 三块。本计划只交付 **M3b-1：SSI + QA-9**；曲面面分割/曲面布尔需要多段 pcurve（当前 `Pcurve2d` 只有直线段）与参数域修剪，列为 **M3b-2**；healing/QA-12 列为 **M3b-3**。理由：SSI 是后两者的输入契约，先把它做成可独立验收、可诊断的组件，避免一个计划同时改拓扑存储、参数域布尔与求交三处高风险代码。

本计划的 SSI 契约（与 §8.6 对齐并收窄）：

- 输入是**未修剪的参数补丁** `SsiPatch{surface, u0,u1, v0,v1}`，不是 B-rep 面；面级调用与 pcurve 生成在 M3b-2 接入。
- 横截（transversal）相交：输出有序折线，`residual <= tolerance`。
- 相切、重合、退化补丁、Newton 不收敛：不输出曲线，返回带参数位置的 `SsiIssue` 诊断码。
- 补丁边界：追踪在参数域边界停止，端点保留最后一个域内精化点；精确边界求交与边拆分请求归 M3b-2。
- 周期参数：Cylinder/Cone/Sphere 的 `u`、Torus 的 `u` 和 `v` 以 `2π` 为周期归一化；参数域跨度必须 ≤ `2π`。

## Review Focus

1. 相切接触（球与平面 `d == r`、圆柱与平面相切）被当作横截线输出——残差合格但拓扑错误；T6 用切点/切线的法向平行检测钉住。
2. 重合曲面（同一平面、同轴等半径圆柱、同一球）返回空集而非诊断；T6 用同参数与镜像参数两种情况钉住。
3. 周期缝（`u` 跨 `0/2π`）处曲线断裂、重复或闭合判定失败；T8 用整球与平面的闭合圆钉住。
4. 补丁边界截断：端点跑出参数域、或边界处残差超 `tol` 仍被接受；T5 用有界平面片与球钉住。
5. NURBS 低平坦度/退化参数化下 Newton 不收敛却返回部分曲线；T1 拒绝非法补丁，T7 用波浪补丁，T9 用不可达容差钉住 `no_convergence`。

- [ ] **Step 3: Implement adaptive tessellation**

对参数域做递归四叉分割，根单元是第 1 层；叶子单元用 4 个角点 + 5 个内部采样（中心、四边中点）与 4 个四分点（0.25/0.75）共 9 点评估；平坦度 = 这 9 点到单元双线性曲面偏差的最大值（双线性而非角平面，才能捕捉鞍形）。超过 `chord_tolerance` 且 `depth < max_depth` 则四分；到达深度上限仍有超差叶子时**照常输出但把 `tolerance_met` 置 false**，`max_chord_error` 记录已接受叶子的最大采样偏差。这两项是采样估计、不是保证。叶子输出 4 个三角形（中心-角-角），角点按 `(u,v)` 网格去重；不同深度的相邻叶子不共形（悬挂节点），裂缝量级为粗叶误差，已文档化。法向用 `surface_normal`（解析面取解析法向，NURBS 用缩放叉积）。`patch_bounds` 不用容差驱动的递归：固定 17×17 角点 + 每格 3×3 子采样，取 AABB 后按 `2×max_sag + 1e-12×diag` 保守外扩；这是采样保守盒，不是精确包围盒。

TEST_CASE("ssi: QA-9 degenerate corpus is either stitched or diagnosed") {
  const double kPi = 3.14159265358979323846;
  int cases = 0;
  int curves = 0;
  int diagnosed = 0;
  const auto check_result = [&](const SsiResult& result) {
    ++cases;
    if (result.curves.empty()) {
      REQUIRE_FALSE(result.issues.empty());
      for (const SsiIssue& issue : result.issues) {
        CHECK(issue.code != SsiDiagnostic::none);
      }
      ++diagnosed;
      return;
    }
    ++curves;
    for (const SsiCurve& curve : result.curves) {
      for (const SsiSegment& s : curve.segments) CHECK(s.residual <= 1e-8);
    }
  };

  // Family 1: sphere tangent to a plane at its south pole (50 radii).
  for (int i = 0; i < 50; ++i) {
    const double r = 0.5 + 0.01 * static_cast<double>(i);
    const Result<SsiPatch> a = make_ssi_patch(
        SurfaceGeometry{Sphere3{Point3d{0, 0, 0}, Vec3d{0, 0, 1}, Vec3d{1, 0, 0}, r}},
        {0, 2 * kPi}, {-0.5 * kPi, 0.5 * kPi});
    const Result<SsiPatch> b = make_ssi_patch(
        SurfaceGeometry{Plane3{{0, 0, 1}, -r}}, {-3, 3}, {-3, 3});
    REQUIRE(a.has_value());
    REQUIRE(b.has_value());
    const Result<SsiResult> result = ssi(a.value(), b.value(), SsiOptions{1e-8});
    REQUIRE(result.has_value());
    check_result(result.value());
  }

  // Family 2: coincident planes written with different normals/scales (50).
  for (int i = 1; i <= 50; ++i) {
    const double d = 0.1 * static_cast<double>(i);
    const Result<SsiPatch> a = make_ssi_patch(
        SurfaceGeometry{Plane3{{0, 0, 1}, d}}, {-2, 2}, {-2, 2});
    const Result<SsiPatch> b = make_ssi_patch(
        SurfaceGeometry{Plane3{{0, 0, -3}, -3 * d}}, {-2, 2}, {-2, 2});
    REQUIRE(a.has_value());
    REQUIRE(b.has_value());
    const Result<SsiResult> result = ssi(a.value(), b.value(), SsiOptions{1e-8});
    REQUIRE(result.has_value());
    check_result(result.value());
  }

  // Family 3: coaxial equal-radius cylinders, offset along the axis (50).
  for (int i = 0; i < 50; ++i) {
    const Cylinder3 a_surface{Point3d{0, 0, 0}, Vec3d{0, 0, 1}, Vec3d{1, 0, 0}, 1.0};
    const Cylinder3 b_surface{Point3d{0, 0, 0.01 * static_cast<double>(i)},
                              Vec3d{0, 0, 1}, Vec3d{1, 0, 0}, 1.0};
    const Result<SsiPatch> a = make_ssi_patch(
        SurfaceGeometry{a_surface}, {0, 2 * kPi}, {0, 1});
    const Result<SsiPatch> b = make_ssi_patch(
        SurfaceGeometry{b_surface}, {0, 2 * kPi}, {0, 1});
    REQUIRE(a.has_value());
    REQUIRE(b.has_value());
    const Result<SsiResult> result = ssi(a.value(), b.value(), SsiOptions{1e-8});
    REQUIRE(result.has_value());
    check_result(result.value());
  }

  // Family 4: torus tangent to the plane z = minor_radius (50 major radii).
  for (int i = 0; i < 50; ++i) {
    const double major = 2.0 + 0.01 * static_cast<double>(i);
    const Torus3 torus{Point3d{0, 0, 0}, Vec3d{0, 0, 1}, Vec3d{1, 0, 0}, major, 0.5};
    const Result<SsiPatch> a = make_ssi_patch(
        SurfaceGeometry{torus}, {0, 2 * kPi}, {0, 2 * kPi});

        SurfaceGeometry{Plane3{{0, 0, 1}, 0.5}}, {-4, 4}, {-4, 4});
    REQUIRE(a.has_value());
    REQUIRE(b.has_value());
    const Result<SsiResult> result = ssi(a.value(), b.value(), SsiOptions{1e-8});
    REQUIRE(result.has_value());
    check_result(result.value());
  }

  CHECK(diagnosed == 200);

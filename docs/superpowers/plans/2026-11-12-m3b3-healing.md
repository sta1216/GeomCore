# M3b-3: Healing 初版 (Stitch + Tolerance Chain) Implementation Plan

> **For the implementing agent:** follow the five-step TDD cycle for every task,
> in order. Run the RED command before writing production code, then the GREEN
> command, then commit. Do not batch tasks into one commit.

**Goal:** Add `heal_brep`, a transactional stitcher that closes small gaps
(1e-6 scale) between open boundary loops of one planar or curved B-rep shell:
weld near-coincident vertices, sew paired boundary edges into shared edges,
raise the tolerance chain explicitly and monotonically, and reject gaps it
cannot close with a located, quantified diagnostic. Satisfies QA-12.

**Architecture:** `heal_brep` edits a `Brep` through `SolidEditor` (the only
mutation path), so every attempt is validated by `commit()` before it is
published. It is a "healing 初版": vertex welding, edge sewing, tolerance
re-assignment, and rejection diagnostics. Small-edge collapse, small-face
removal and surface re-fitting are explicitly deferred to M4 (architecture
§8.12, milestones table).

**Tech stack:** C++20, header-only `geom::v1`, doctest, CMake target
`geom_tests`, MSVC `/W4 /WX /utf-8`, GCC/Clang `-Wall -Wextra -Wpedantic`.

**Spec:** `docs/architecture/geometry-library-architecture.md` §8.12 (healing),
§4.6 (tolerance chain), §12.6 (QA-12: 1e-6 gap assembly is either bridged with
a self-consistent tolerance chain, or rejected with the gap location and
magnitude). `docs/quality/testing-strategy.md` (positive/boundary/failure per
public API; no weak assertions; determinism).

---

## Global Constraints

- Header-only: all new code lives in `include/geom/brep/…` with `inline`
  functions; one new `.cpp` is not allowed.
- `heal_brep` never mutates its input and never publishes a partially-healed
  Brep: on any rejection the returned `HealResult::brep` equals the input.
- Only boundary edges of the target solid are considered. Boundary edges of
  other solids are ignored.
- Tolerances are monotone non-decreasing and explicit: every raise is reported
  through `HealReport::max_tolerance`. Global epsilon and "raise until it fits"
  are forbidden (architecture anti-pattern list).
- Every error is a `Result` error or a `HealIssue`; no exceptions, no `assert`
  as the only check.
- Determinism: two identical inputs produce byte-identical Breps and equal
  reports; candidate order is by (edge index, edge index).
- Tests use `tests/unit/brep_heal_test.cpp` and
  `tests/unit/brep_heal_fixture.hpp`; register the test file in
  `tests/CMakeLists.txt` `GEOM_TEST_SOURCES`.

## Scope And Deviations To Approve

1. **Single solid, welded vertices + sewn edges only.** Face splitting and
   non-manifold stitching are out of scope. A healed shell must end up closed
   (each edge used exactly twice inside the shell).
2. **No small-edge collapse / face removal / NURBS re-fit.** Those are M4 per
   the milestone table; the plan documents them as deferred and keeps the
   report fields extensible.
3. **Pairing is mutual-nearest, not global optimum.** It is O(n²) over boundary
   edges with an early AABB reject; healing is an offline operation. Ambiguous
   ties are rejected, never guessed.
4. **Tolerance semantics:** a welded vertex takes
   `max(tol_keep, tol_drop, distance)`; edges dominate their vertices, faces
   dominate their edges and coedges, the solid dominates its faces. No value is
   ever lowered.

## Review Focus

- Transactionality: a failed `commit()` must return the original Brep and a
  diagnosis, not a partial stitch.
- Tolerance chain: after a successful heal,
  `validate_tolerances(brep).ok()` is true and every raised value is reported.
- Pairing: direction compatibility, ambiguity rejection, and determinism.
- QA-12 both ways: 1e-6 gap closes to a valid closed solid; 1e-3 gap is
  rejected with a location within the gap band and the measured magnitude.

## Task 1: Public healing surface and boundary discovery

**Files:** create `include/geom/brep/heal.hpp`, `tests/unit/brep_heal_test.cpp`;
modify `tests/CMakeLists.txt`.

**Interfaces (Produces):**

```cpp
namespace geom::v1 {

enum class HealIssueKind : std::uint8_t {
  none, gap_too_large, ambiguous_gap, inconsistent_orientation, invalid_result
};
const char* to_string(HealIssueKind kind) noexcept;

struct HealOptions {
  double tolerance = 1e-9;  // resolution used by the caller; reported, not overwritten
  double max_gap = 1e-6;    // largest vertex-to-vertex distance that may be welded
};

struct HealIssue {
  HealIssueKind kind = HealIssueKind::none;
  Point3d location{};
  double gap = 0.0;
  const char* message = "";
};

struct HealReport {
  std::uint32_t boundary_edges = 0;
  std::uint32_t welded_vertices = 0;
  std::uint32_t sewn_edges = 0;
  double max_closed_gap = 0.0;
  double max_tolerance = 0.0;
  bool changed = false;
  std::vector<HealIssue> issues;
};

struct HealResult {
  Brep brep;
  HealReport report;
};

// Structural preconditions: live solid id, finite options, loops closed,
// every edge used at most twice. Open shells are allowed (that is the input
// state of a gap). Returns invalid_topology / non_finite / tolerance_violation
// for bad input; otherwise never errors for geometric reasons (rejections are
// reported in HealReport::issues with the input Brep returned unchanged).
Result<HealResult> heal_brep(const Brep& brep, SolidId solid, const HealOptions& options);

namespace detail {
// Boundary edges of `solid`: edges used exactly once by the faces of its
// shells. Sorted ascending by index. Empty when the solid is unknown or closed.
std::vector<EdgeId> heal_boundary_edges(const Brep& brep, SolidId solid);
}  // namespace detail
}  // namespace geom::v1
```

**Test sketch:**

```cpp
TEST_CASE("heal: boundary edges of a closed box are empty") {
  const Brep box = geom::v1::make_box({0, 0, 0}, {1, 1, 1}, 0.0).value();
  const SolidId solid = box.solid_ids().front();
  CHECK(geom::v1::detail::heal_boundary_edges(box, solid).empty());
}

TEST_CASE("heal: an open quad sheet exposes four boundary edges") {
  SolidEditor editor;
  const auto s = editor.add_surface(Plane3{{0, 0, 0}, {0, 0, 1}});
  const auto v00 = editor.add_vertex({0, 0, 0}, 0).value();
  const auto v10 = editor.add_vertex({1, 0, 0}, 0).value();
  const auto v11 = editor.add_vertex({1, 1, 0}, 0).value();
  const auto v01 = editor.add_vertex({0, 1, 0}, 0).value();
  const auto e0 = editor.add_edge(v00, v10, kNoGeometry, 0, 1, 0).value();
  const auto e1 = editor.add_edge(v10, v11, kNoGeometry, 0, 1, 0).value();
  const auto e2 = editor.add_edge(v11, v01, kNoGeometry, 0, 1, 0).value();
  const auto e3 = editor.add_edge(v01, v00, kNoGeometry, 0, 1, 0).value();
  const auto face = editor.add_face(s, false, 0).value();
  const CoedgeSpec loop[] = {{e0, false}, {e1, false}, {e2, false}, {e3, false}};
  editor.add_loop(face, loop, true);
  const auto shell = editor.add_shell({face}, false).value();
  editor.add_solid({shell}, 0);
  const Brep brep = editor.commit().value();
  CHECK(geom::v1::detail::heal_boundary_edges(brep, brep.solid_ids().front()).size() == 4);
}
```

## Task 2: Editor primitives for welding, sewing and shell closure

**Files:** modify `include/geom/brep/solid_editor.hpp`;
`tests/unit/brep_heal_test.cpp`.

**Interfaces (Produces):**

```cpp
// Inside SolidEditor:
// Merge `drop` into `keep`: every edge endpoint pointing at `drop` is
// retargeted to `keep`, `keep.tol` becomes the maximum of both tolerances and
// the true distance, and `drop` is released. Fails with index_out_of_range for
// dead handles or the same handle, and with unsupported if the merge would
// create a self-loop edge (v0 == v1).
Result<void> merge_vertices(VertexId keep, VertexId drop);

// Merge the boundary edge `drop` into `keep`: every coedge using `drop` is
// retargeted to `keep` with `reversed` recomputed from the endpoint
// correspondence, `keep.tol` becomes the maximum of both edge tolerances, and
// `drop` is released. Both edges must have two distinct live endpoints that
// are already welded pairwise; otherwise returns invalid_topology.
Result<void> merge_edges(EdgeId keep, EdgeId drop);

// Set the shell's closed flag. Throws nothing; returns invalid_topology if the
// shell is dead, tolerance_violation if the shell would claim closed while any
// of its edges is used fewer than twice inside that shell.
Result<void> set_shell_closed(ShellId shell, bool closed);

// Raise the staged tolerance chain monotonically: every edge to at least the
// maximum of its two vertex tolerances, every face to at least the maximum of
// the tolerances of the edges and coedges it uses, every solid to at least the
// maximum face tolerance in its shells. Returns the largest value set (0 when
// nothing changed).
Result<double> raise_tolerances();
```

**Steps:**

1. Add tests: welding a duplicated vertex retargets its edges and raises its
   tolerance to the distance; welding a vertex to itself fails; merging two
   boundary edges leaves one edge with two opposite coedge directions; setting
   `closed=true` on a sheet with boundary edges fails, and succeeds once the
   sheet is actually closed.
2. Run: RED (methods missing).
3. Implement in `solid_editor.hpp`, reusing `staged_`, the allocators, and the
   same error strings as the existing methods.
4. GREEN, then commit `feat(m3b3): add editor primitives for stitching`.

Implementation notes:

- `merge_vertices` must scan `staged_.edges_` once; for each edge whose `v0`
  or `v1` equals `drop`, retarget and update tol. Then check the edge is not a
  self-loop, release `drop`, and bump `generation` via the allocator (the
  allocator's `release` already does this).
- `merge_edges` recomputes direction as
  `reversed_new = (traversal_start_after_weld != keep.v0)`, where
  `traversal_start_after_weld` is `coedge.reversed ? drop.v1 : drop.v0`’s
  welded survivor. It must also copy the drop edge's curve only when `keep`
  has no curve (`keep.curve == kNoGeometry`), and never widen `keep.tol`.
- `set_shell_closed(true)` counts uses per edge restricted to the shell's faces
  and fails if any count differs from two.

## Task 3: Pairing plan and the healing pipeline

**Files:** `include/geom/brep/heal.hpp`; create
`tests/unit/brep_heal_fixture.hpp` (initially only `TornSheet`);
`tests/unit/brep_heal_test.cpp`.

**Interfaces (Produces):**

```cpp
namespace detail {
struct HealEdgePair {
  EdgeId keep{};      // lower index
  EdgeId drop{};      // higher index
  bool same_direction = false;  // coedge traversal directions agree
  double gap = 0.0;             // max endpoint distance under the best mapping
};

struct HealPlan {
  std::vector<HealEdgePair> pairs;
  std::vector<HealIssue> issues;
};

HealPlan heal_plan(const Brep& brep, std::span<const EdgeId> boundary,
                   double max_gap);

// Endpoint correspondence used by the welder: returns {pairs, gap}; pairs are
// (keep_vertex, drop_vertex) with keep.index() < drop.index().
}  // namespace detail
```

Tolerance raising is `SolidEditor::raise_tolerances()` (Task 2), called after
the welds and shell closure, before `commit()`.

**Algorithm:**

1. For each unordered boundary pair `(i, j)` compute both endpoint matchings
   `d00+d11` and `d01+d10`, keep the smaller sum; `gap = max` of the two
   distances in that matching; reject pairs with `gap > max_gap`.
2. A pair is *mutual* when `j` is `i`'s best and `i` is `j`'s best. Ties
   within `1e-6` relative are `ambiguous_gap` and are skipped.
3. Direction compatibility: take the coedge that uses the boundary edge; its
   traversal direction after matching must be opposite on the two rims. If both
   rims traverse the seam the same way, emit `inconsistent_orientation` and do
   not sew.
4. Unpaired edges whose nearest partner gap exceeds `max_gap` are collected and
   reported as **one** `gap_too_large` issue: the closest such pair (smallest
   gap; tie broken by lower edge indices), with `location` = midpoint of the
   closest endpoint pair and `gap` = that distance. Reporting one issue keeps
   the diagnostic stable when a whole rim is too far away.
5. `heal_brep`: collect boundaries → plan → for each pair call
   `merge_vertices` on both endpoint pairs (keep lower index) → `merge_edges` →
   for each shell of the solid call `set_shell_closed(true)` when all its edges
   are used twice → `raise_tolerances()` → `commit()`.
   - Pairs that are within `max_gap` are healed even when other boundary edges
     are reported as `gap_too_large`; the report then contains both counters and
     the issue.
   - If any shell of the target solid still has a boundary edge after sewing,
     do not publish: return the original Brep with one `invalid_result` issue
     `"heal_brep: a shell is still open after stitching"`. A partial stitch is
     never silently published.
   - On `commit()` failure, return the original Brep and append one
     `invalid_result` issue carrying the `Error::message`.
   - On success, fill the report counters and `changed = (welded+sewn) > 0`.
   - No pairs and no issues ⇒ unchanged result, `changed=false`.

**Steps:**

1. Tests: two quads facing each other with a 1e-6 seam produce two pairs with
   `gap≈1e-6`; a 1e-3 seam with `max_gap=1e-6` produces `gap_too_large` with
   the measured magnitude; two rims whose coedges run the same way produce
   `inconsistent_orientation`; a closed box produces no pair and `changed=false`.
2. RED (helpers missing).
3. Implement, then GREEN.
4. Commit `feat(m3b3): plan boundary stitches and heal transactionally`.

Pairing test sketch:

```cpp
TEST_CASE("heal: a 1e-6 seam is paired") {
  const geom::test::TornSheet sheet = geom::test::make_torn_sheet(1e-6);
  const auto boundary = geom::v1::detail::heal_boundary_edges(sheet.brep, sheet.solid);
  REQUIRE(boundary.size() == 8);  // four per rim

  CHECK(plan.issues.empty());
```

## M3b-3 Exit Criteria

- QA-12: 1e-6 gap assembly heals into a closed, validated solid with volume 1
  (1e-9) and a self-consistent tolerance chain; 1e-3 gap is rejected with its
  location and magnitude, input unchanged.
- `heal_brep` is deterministic and idempotent on healed input.
- All tests pass in Debug and Release; no warnings; `git status` clean.
- Deferred items are documented: small-edge/face removal, surface re-fit,
  multi-solid stitching, and curved gap bridging beyond vertex/edge pairs.

# M3.5b: close QA-9 and make an honest QA-1 decision

## Goal

Close the QA-9 gate (sphere-plane SSI median <= 100 us) with an exact analytic
fast path, and improve QA-1 (two-star union) with the one measured cheap win.
Decide QA-1's gate explicitly in an ADR: the measured floor makes 80 ms
impossible for this fixture, so the gate must be revised with evidence rather
than silently declared passing.

## Architecture / Tech Stack

C++20 header-only geometry core, CMake + MSVC/VS2022 (warnings as errors),
doctest, GitHub Actions matrix. Benchmarks: `geom_bench_ssi` (QA-9) and
`geom_bench_m1b` (QA-1/QA-4). Gate evidence comes from Release builds only.

  boolean/arrangement contract and QA-1.

## Global Constraints

- Exact geometry where the fast path claims analytic output; no caching, no
  tolerance-based shape changes, no silent fallback that changes results.
- Every sphere-plane case the fast path does not certify must fall through to
  the existing generic path bit-for-bit.
- Public behaviour for non-(sphere, plane) pairs, partial/trimmed domains,
  tangency, coincidence, and beneath-resolution cuts is unchanged.
- Determinism: identical inputs produce identical curves and params; argument
  order swaps patch roles but not the geometric curve.
- No new dependencies; header-only; `/W4 /WX` clean.
- Fast-lane process: task gates are targeted Release filters; milestone end
  runs both full suites. Reviewer reuses the M3.5 reviewer and trusts
  implementer counts, re-running only targeted probes.

## Task 1: exact analytic sphere-plane SSI

Files:
- `include/geom/brep/ssi.hpp` (new `detail::ssi_try_analytic_sphere_plane`,
  called once per pair right after option validation and before `patch_bounds`:
  the bounds and tangency predicates sample grids that cost milliseconds, while
  the analytic chart needs none of them. The path reproduces the resolution
  floor with a scale check so beneath-resolution requests still fall through.)
- `tests/unit/ssi_test.cpp`.

Interface:
```cpp
namespace detail {
// Returns true when the pair is a horizontal sphere/plane cut that this exact
// path certifies; fills `result` completely. Returns false to fall through.
inline bool ssi_try_analytic_sphere_plane(const SsiPatch& a, const SsiPatch& b,
                                          const SsiOptions& options,
                                          double chord_tolerance,
                                          SsiResult& result);
}
```

Algorithm:
1. Identify `(Sphere3, Plane3)` in either order; require the plane normal to be
   parallel to the sphere axis (`norm2(cross(unit(n), unit(axis))) <= 1e-12`),
   the sphere `u` domain to cover a full period, and the circle to be inside
   both domains (v band and plane rectangle, sampled at 64 points with a
   tolerance margin).
2. Chord budget `max(1e-3 * 2r, 64 * tolerance)` (the sphere diameter is the
   scale the fast path controls; the union-patch diagonal is not needed).
   Signed axial distance `d = plane.signed_distance(center)`, circle radius
   `rho = sqrt(r^2 - d^2)`. If `|d| >= r`, return the empty result (no curve).
   If `r - |d| <= max(1e-12 * (1 + r + |d|), 0.05 * tolerance)`, report
   `tangent_contact`, matching the generic tangent floor. If
   `rho <= chord_tolerance`, return false so the generic path reports the
   beneath-resolution diagnostic.
3. Emit `N = max(8, ceil(pi / acos(1 - chord_tolerance / rho)))` points around
   the circle; `SsiSegment`s with sphere params `(u, asin(d/r))` (u unwrapped
   along the traversal), plane params from `make_plane_frame`, `residual`
   from `ssi_residual`; `closed = true`; the last segment ends at the first
   point. `candidate_pairs = 0`, `accepted_segments = N`,
   `rejected_segments = 0`.
4. Caller assembles `max_residual` and ordering exactly as today.

Tests (targeted `-tc=*ssi*`):
- New: exact circle center/radius for tilted axis and translated sphere;
  `segments >= 8`, closed, every endpoint on both surfaces within 1e-12;
  argument-order symmetry (same geometry, swapped roles); `candidate_pairs ==
  0`; `max_residual <= 1e-9`; a partial-u sphere and an oblique plane still
  take the generic path (compare counts with a control).
- Update the counter test that pins sphere-plane `31/65/96` to the analytic
  `50/0/96` and state why the extracted count still comes from mesh
  extraction.
- Add the QA-9 fixture as a unit-level repeatability check (two calls equal).

Acceptance:
- `geom_bench_ssi` Release median <= 100 us, PASS, curves non-empty,
  residual <= 1e-9.
- `-tc=*ssi*` all green; no other test changed.

## Task 2: QA-1 inline disjoint reject

Files: `include/geom/cgeom/arrangement2.hpp` (sweep loop), optionally
`tests/unit/arrangement2_test.cpp` if a regression is added.

Change: hoist the cheap same-side reject into the active-set loop (the probe
measured 3.37M candidates, ~35 ns each; inlining saves about 100 ms of the
914 ms total). Keep the exact classifier as the only authority; the inline
test may only reject pairs that are provably disjoint in double arithmetic.
Ask the analyst for the exact 10-LOC patch before editing.

Acceptance: `geom_bench_m1b` union time recorded before/after, area identity
unchanged, `-tc=*arrangement*,*boolean*` green.

Result (2026-11-23): interleaved A/B runs measured base 919/923/965 ms and
inline 928/931/973 ms. MSVC already inlines `split_record_pair`, so the hoist
does not recover the probe build's 100 ms; the change was reverted and T2 is
recorded as a measured negative. No test changed.

## Task 3: QA-1 gate decision and docs

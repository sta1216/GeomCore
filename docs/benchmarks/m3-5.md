# M3.5a benchmark: BVH and box meshing

Date: 2026-11-23. Machine: Intel i7-8550U (4 cores), Windows 11, MSVC 19.44, Release, `/W4 /WX`. Numbers are medians of three clean process runs unless stated otherwise.

## Commands

```
cmake -S . -B build-bench -DGEOM_BUILD_BENCH=ON
cmake --build build-bench --config Release --target geom_bench_m1b geom_bench_m2
.\build-bench\Release\geom_bench_m1b.exe
.\build-bench\Release\geom_bench_m2.exe
```

The M1b benchmark checks the build budget and the 8 Mray/s raycast budget; it exits 2 when the raycast budget fails. The M2 benchmark runs QA-10 and QA-11.

## BVH (QA-4)

| metric | before | after | budget |
| --- | ---: | ---: | ---: |
| build 1M triangles | 1,372 ms | 287-300 ms | 350 ms PASS |
| raycast | 0.45 Mray/s | 0.66 Mray/s | 8 Mray/s FAIL |
| nearest (1M points) | not gated | ~0.7-1.0 Mray/s (DRAM floor measured) | - |

Build phases after the change (profile, one run): SAH binning and scatter dominate; median selection is confined to the straddling bin for normal binned splits (degenerate parents still use a full-range median and rescan both halves); child boxes come from prefix/suffix unions; the top three frontiers are built in parallel and concatenated deterministically. Serial and parallel builds give identical public query results; node numbering may differ.

Raycast: the median is 0.66 Mray/s (1.47x baseline) and stays below the 0.9 single-ray target and the 8 Mray/s budget. With primitive work removed the single-ray latency floor measured 0.87-0.91 Mray/s, so 8 Mray/s needs packets/SIMD and is deferred. Float child boxes were rejected: 4000 coplanar rays produced 619 wrong primitives because a float entry time can round one ulp above a real hit. Double boxes plus `best * (1 + 1e-12)` in the five box prunes are conservative; leaf acceptance stays exact.

## Box meshing (QA-10)

| metric | before | after | budget |
| --- | ---: | ---: | ---: |
| 16,666 boxes | 926.8 ms | 107-138 ms | - |
| per box | 55.6 us | 7.3-8.2 us | 12 us PASS |
| throughput | 0.22 Mtri/s | 1.46-1.65 Mtri/s | 1.0 Mtri/s PASS |
| watertight / outward | yes | yes | required |

The fast path recognizes the canonical box and emits the same 12 triangles from the same welded indices in the same order. A parity test compares the default path with `detail::tessellate_impl(..., false)` for four boxes at two deflections: 8 positions bit-equal coordinate by coordinate, 12 triangles, identical `triangle_face`. Canonical hashes for box/cylinder/torus are unchanged. The generic path is still used for holed, curved, concave and non-rectilinear input.

## Unchanged gates

QA-1 (2D union) measures 887-1,037 ms in this slice; no QA-1 code was touched, so this is run variance around the earlier 1.9 s sample and still a budget failure (80 ms) and QA-9 (SSI) 9.6-19.5 ms (budget 100 us); both are the next performance slice. QA-11 mass properties remains within 7.62e-10 relative error.


## M3.5b: QA-9 closed, QA-1 gate decision

Date: 2026-11-23. Same machine and configuration.

### QA-9 (SSI sphere-plane)

| metric | before | after | budget |
| --- | ---: | ---: | ---: |
| median | 9.7-10.1 ms | 53.5 us | 100 us PASS |
| min / max | - | 53.0 / 303.1 us | - |
| candidate pairs | 14,848 | 0 | - |
| accepted segments | 31 of 96 extracted | 50 analytic | - |
| max residual | 6.44e-10 | 1.57e-16 | <= 1e-9 |

The fast path detects a sphere and a plane whose normal is parallel to the
sphere axis, certifies that the whole latitude circle lies inside both patch
domains, and emits the exact circle without tessellation or Newton. Requests
that are not certified (partial domains, oblique planes, tangency,
beneath-resolution tolerance) fall through to the generic tracer unchanged.
The residual is computed with the same `ssi_residual` used by the tracer.

### QA-1 (2D union)

Measured 920-970 ms (median 923 ms over interleaved runs). The 80 ms budget is
not attainable for this fixture: bbox enumeration alone is 242 ms and the DCEL
adds 340 ms. See ADR-0040 for the stage table and the proposed 1,000 ms gate
(awaiting owner approval; the benchmark still fails). The inline disjoint
rejection was measured A/B and reverted: MSVC already inlines the pair handler,
so it gained nothing here.

# M3c-3c-4b3c-2: cone cuts through the axis

Date: 2026-11-22

## Scope

This note records the six cases added for whole-cone/plane booleans whose cutting
plane contains the cone axis (M3c-3c-4b3c-2), plus the predicate pin and the
existing translated-cone refusal used as a control. It covers the three boolean
operations on the canonical cone, the rotated and translated placements, the three
refusal cases, volume and topology counts, and the focused Debug/Release timings.
There is no timing gate: the numbers below are one run per configuration on the
machine described here.

## Environment

- Windows 10 Enterprise 10.0.19045 x64; Intel Core i7-8550U, 4 cores / 8 threads,
  15.9 GB RAM.
- MSVC 19.44 (Visual Studio 17 2022, toolset 14.44.35207); CMake 4.4.4.
- Debug and Release, `GEOM_WERROR=ON`, `/W4 /WX /utf-8`; single run per
  configuration.
- Test binary: `build/tests/<Config>/geom_tests.exe`; filter
  `-tc="curved boolean:*"`, `-ni -d` for the per-case times.

## Fixture

Canonical cone: `make_cone({0,0,0}, +z, radius 1, height 2, 1e-9)`; cutter box
`{0,-1.5,-0.5}..{1.5,1.5,2.5}`. The plane `x=0` contains the axis, so the
section is two rulings and the cut on the lateral face is two meridians from
the apex to the base rim. Boolean tolerance is `1e-9` in every case.

Rotated placement: cone axis `+x`, box `{-0.5,0,-1.5}..{2.5,1.5,1.5}`.
Translated placement: cone origin `(0,5,0)`, box `{0,3.5,-0.5}..{1.5,6.5,2.5}`.

The canonical timing covers all three operations and the determinism repeat; the
other rows are single-operation cases. The focused run totals 51/51 cases and
1492/1492 assertions in 78.8 s on Release and 658.7 s on Debug. A second
post-message pair took 101.7 s and 1082.8 s (10.6x), and the Task 3 focused run
measured 9.8x: the 4-core laptop varies with sustained load, so treat Debug as
roughly 10x slower rather than a precise multiplier. Individual geometry cases
range from about 8x to 14x; the predicate pin is sub-millisecond in both
configurations. This is expected for the debug C++ runtime and is not a regression
signal.

## Tolerances

- Boolean tolerance: `1e-9` (caller-supplied).
- Volume assertions in the test: `1e-12` absolute against the analytic values.
- Measured relative error against the analytic volume: at most `3.4e-15` in this
  matrix.
- Topology: one shell, closed by uses, `validate_topology` clean, zero zero-length
  3D edges.

## Refusals and determinism

- Near-apex box `{0,-1.5,1.5}..{1.5,1.5,2.5}`: `Errc::unsupported`, no entity.
  The observed message is `"split_face_curved: open cut crosses the seam"`, but
  this case deliberately pins no message because the refusal is downstream of the
  cone gate.
- Cutter face narrower than the cone diameter, box
  `{0,-1.5,0.2}..{1.5,1.5,1.0}`: `unsupported`,
  `"trim_face: cut chain ends inside the parameter domain"`.
- Cutter plane containing a seam ray, box
  `{-1.5,0,-0.5}..{1.5,1.5,2.5}`: `unsupported`,
  `"boolean_solid_curved: result touches itself along an edge"`.
- The existing translated-cone coincident-seam refusal is unchanged and remains
  deterministic.
- The canonical, rotated and translated differences repeat bitwise; no refusal
  returns a partial entity.

## Focused and full runs

Focused Release: 51/51 cases, 1492/1492 assertions, 78.8 s wall.
Focused Debug: 51/51 cases, 1492/1492 assertions, 658.7 s wall in the timed run and
1082.8 s on a second post-message run.
Full Release and full Debug: 1038/1038 cases, 674,758/674,758 assertions, zero

not separately timed for this note). The focused counts include the six new cases
and the predicate pin; the full counts are unchanged by the Task 4 message-only
edit.

## Limits

- Oblique planes (ellipse sections) and offset-parallel planes are still refused;
  the gate message names M3c-3c-4b3.
- Reversed difference is deferred by the flipped-fragment limitation.
- Cone/cone, cone/torus, cone/cylinder and cone/sphere pairs are not supported.
- Trimmed cone fragments are not accepted as boolean operands.
- A cutter narrower than the cone diameter is refused by the parameter-domain
  trim, not by a dedicated diagnostic.
- Seam-ray cutters are refused by the self-touch guard.
- The apex-copy exemption is local to the seam-copy guard; it does not legalise
  translated cones whose seam copies truly coincide.
- Same-face double pole-run merging and a dedicated apex-only diagnostic remain
  deferred.

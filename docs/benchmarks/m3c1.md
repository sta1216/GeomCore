# M3c-1 修剪曲面网格化与质量属性 QA-13 证据（2026-11-13）

**结论：QA-13 通过。** 60 度开窗圆柱的修剪侧面在 `deflection = 2e-3` 下网格
水密（每条边恰好 2 次使用）、坐标有限、逐面分组正确，两次运行逐位一致
（893 个用例、657,831 条断言，Debug 与 Release 相同，`/W4 /WX /utf-8` 零警告）；
弦高偏差 `≤ deflection`，同一夹具在 1e-2/2e-3/1e-3/1e-4 下的三角形数为
468/894/1268/3744（细化随弦高单调增）；修剪质量属性与解析值相对误差
`4.4e-10`（r=1）与 `4.4e-11`（r=10），远优于文档门禁 1e-5。孔洞与斜切修剪
边界仍是显式 `unsupported`（M3c-2）。

## 测量定义

- **exact volume**：`detail::curved_solid_volume(brep, solid, 1e-9)`，本夹具为
  `5.826573829688656`；解析闭式 `2*pi - (sqrt(3)/4 + pi/6 - 1/2)` =
  `5.826573829689068`（窗口面积 `0.4566114774905181`，高 1）。两者相差
  `4e-13`，是体积积分器自身的求积下限。
- **mesh volume / rel**：网格有向体积（四面体求和）与 exact 的相对误差；
  弦高 `d` 的离散误差为 `O(d)`，测试门禁为 `2*d`（2e-3 时 4e-3）。这不是代码里
  的弦高门禁：代码与弦高用例检查的是三角形边中点相对曲面的偏差
  `<= deflection`，`2*d` 只是体积误差的保守上界。
- **watertight**：`check_watertight`，每条无序边使用次数必须为 2。
- **deterministic**：两次独立 `tessellate()` 的 `positions` 逐字节（`memcmp`）、
  `triangles`、`triangle_face` 完全相同。
- **mass rel**：`mass_properties` 体积与 exact 的相对误差；质心/惯量张量见下表。
- **QA-13**：单用例，覆盖水密、有限、索引合法、逐位确定性与逐面分组。

## 质量属性

`MassPropertiesOptions{1e-9, 24, 1e-5}`；四边域按角点三角化（12 个三角形），
Dunavant 7 点在精确曲面上积分。

| 夹具 | 体积 | 相对 exact | 质心 | 惯量（对角） |
| --- | --- | --- | --- | --- |
| r=1 开窗圆柱 | 5.826573827129446 | 4.392e-10 | (-0.057209149585, 0, 1) | 3.592034030768, 3.356457963297, 2.835803705475 |
| r=10, h=5 缩放窗口 | 1433.812883484877375 | 4.379e-11 | — | — |

两者非对角分量 < 1e-13；r=1 的惯量在质心处，解析值
`(3.5920340332341665, 3.3564579658203764, 2.8358037071487563)`（brief 的 Iyy
`3.5729643167320004` 是绕原点的值，已在 Task 4 修正）。步长下限
`max(sqrt(8*curved_sampling_deflection), 5e-2 rad)` 使默认调用实测约 46 ms
（整个 8 面实体），r=10 缩放面约 65 ms；它在
`curved_sampling_deflection <= 3.125e-4` 时生效，只限制内部求积密度与运行时间，
不限制可测精度（上表 4.379e-11 / 4.392e-10 即默认步长下的结果）。

## 显式不支持的语料

| 输入 | 结果 |
| --- | --- |
| 开窗圆柱，窗口在 +y、不跨缝合线（2 个环：外环 + 孔） | `Errc::unsupported`，`tessellate: trimmed curved face has a hole`（与 deflection 无关） |
| 斜切圆柱（`split_solid_by_plane`，椭圆 uv 边界） | `Errc::unsupported`，`tessellate: trimmed curved face boundary is not rectilinear`（与 deflection 无关） |
| 孔洞 / 斜切修剪面的 `mass_properties` | `Errc::unsupported`（"has a hole" / "boundary is not rectilinear"） |
| 度为 2 及以上的 NURBS 修剪边 | `Errc::unsupported`（gate 与采样器都只接受度为 1 的多段线） |
| 球 / 圆环 / 锥作为布尔操作数 | 曲面包尔本身只支持圆柱，M3c-2 |

## 范围与限制

- 只覆盖圆柱侧面 + 平面修剪（曲面包尔当前的操作数组合）；球/圆环/锥与
  度 >= 2 的 NURBS 修剪轮廓是 M3c-2。
- 修剪面必须落在单个外环上：孔洞（窗口不跨缝合线时产生的两环）与斜切
  （椭圆 uv 边界）显式 `unsupported`，不会静默退化成矩形。
- 网格体积的 `O(deflection)` 偏差来自弦高离散（2e-3 时 9.3e-4），不是
  面积/朝向缺陷；质量属性走曲面上的 Dunavant 积分，不受弦高影响。
- 布尔输出在裁剪线附近留有 190 个同面 `7e-13` 量级的擦边点（
  `1e-12` 绝对容差下 0 个 T 型接缝，`1e-9` 相对容差下为同面擦边），
  这是布尔采样精度而非网格化缺陷。
- 本文是 QA-13 正确性证据，不是吞吐基准；网格化与质量属性的逐次耗时只
  记录在 Task 2/Task 4 报告中。

# M3c-2 圆环曲面布尔 QA-14 与基准（2026-11-14）

本文件记录 M3c-2 出口的两部分证据：QA-14 三行圆环矩阵，以及
`boolean_solid_curved` 在三个圆环操作上的逐操作耗时。数字为单机单次测量，
基准没有时间门禁，只记录实测值，不是跨机器承诺。
**结论：QA-14 3/3 通过（功能 PASS，两次运行体积逐位相同）；基准中位数
布尔调用 111.6 / 110.8 / 24.1 ms，体积积分 716.9 / 1334.0 / 561.7 ms，
其中体积积分是主要成本，没有时间门禁。**

## 口径

- **操作数**：`make_torus({0,0,0}, {0,0,1}, 1.0, 0.5, 1e-9)`（R = 1、r = 0.5，
  轴 +z）与三个轴对齐盒体：`z ≥ 0` 盒 `(-2,-2,0)..(2,2,2)`、`x ≥ 0` 盒
  `(0,-2,-2)..(2,2,2)`（切割平面包含环轴，交线跨 `v` 缝）、包含盒
  `(-2,-2,-2)..(2,2,2)`。
- **解析体积**：圆环体积 `2π²Rr² = 4.934802200544679`；被包含轴的平面切成两半
  时每半 `2.4674011002723395`。
- **QA-14**（`tests/unit/curved_boolean_qa14_test.cpp`）：每行要求
  `boolean_solid_curved` 成功、`validate_topology().ok()`、恰好一个实体且
  所有 shell `closed`、体积相对误差 ≤ 1e-6；切割行还要求 `cuts >= 1`、
  `kept >= 1`、`max_cut_residual <= 1e-3`，包含行要求 `cuts == 0`。每行跑
  第二次，要求体积逐位相同（`==`）且 `cuts`/`kept`/残差相等。
- **基准**（`bench/bench_m3c2.cpp`）：每个操作先跑一次不计时的预热（校验
  拓扑与闭合 shell），再用 `std::chrono::steady_clock` 计时 100 次；计时区间
  分成一次完整的 `boolean_solid_curved` 调用与一次
  `detail::curved_solid_volume` 调用两部分，分别给出 min/median/p95/max。
  每次迭代都按 1e-6 相对校验体积，拓扑只在第一次与最后一次校验。退出码：
  0 全部校验通过，1 校验或体积失败，2 构造/驱动错误。
- **采样**：操作数按默认 `TessellationOptions`（弦高 1e-3）分类；布尔结果的
  修剪面环在 uv 上按每个 coedge 32 段采样（`face_loops_uv`），体积积分对
  多边形先做 `1e-12 · uv 尺度` 的冗余点简化，再三角化并逐三角形 7 点
  Dunavant 在精确曲面上积分。驱动没有采样预算旋钮，这里记录**实际**行为。
- **单位**：毫秒；无时间门禁，`PASS` 只代表校验通过。

- 三个操作的布尔调用中位数 111.6 / 110.8 / 24.1 ms；体积积分中位数
  716.9 / 1334.0 / 561.7 ms。体积积分是布尔调用的 6–12 倍（两条切割行；包含盒行约 18–23 倍），因为修剪面环
  每个 coedge 采 32 段（圆环四个面环在含轴切割里约有数百个 coedge），积分器
  要把 uv 多边形三角化并在每个子三角形上打 7 个点，子三角形数量由 uv 边长
  决定（上限 8 级）。
- 包含盒一行最便宜：只有一个面环、没有切链，简化后几乎是整矩形，布尔调用
  中位数 24.1 ms。
- **波动**：同机此前的部分运行里 `torus-z-half` 布尔中位数为 104.7 ms
  （min 66.1、p95 143.7、max 627.6），本次为 111.6 ms；含轴切割一行体积
  p95 是 1634.7 ms、max 是 1967.7 ms，主要来自与同机其他进程争用的抖动。
  量级稳定，绝对数字只作本机参考。
- 成本结构：每个操作都重新构建两个分类网格（圆环面 1 个面 + 盒体 6 个面）、
  枚举面片对做 SSI、切分环面与盒面并装配；布尔驱动没有跨调用缓存。体积积分
  每次都在新结果上重新采样，因此单独计时。

## 结论

1. **QA-14 PASS**：三行（垂直轴平面、跨 v 缝的含轴平面、包含盒）全部是
   `validate_topology` 干净的闭合实体，体积相对误差 ≤ 1e-6，两次运行体积
   逐位相同；切割行残差 `9.9e-10` 与 `9.2e-17`，都远低于 `1e-3`。
2. **基准无时间门禁**：记录的是本机实测值，布尔调用中位数 111.6 / 110.8 /
   24.1 ms，体积积分中位数 716.9 / 1334.0 / 561.7 ms，三项全部校验通过
   （`verified=yes`，退出码 0）。
3. 平面限制下圆环操作数与 v 缝都可以端到端使用，结果可重复；球、锥、偏移
   平行/倾斜环切平面仍是显式 `unsupported`。
4. 全套测试 Debug 与 Release 各 933 个用例、659,233 条断言全绿；
   `/W4 /WX /utf-8` 零警告。

## 范围与限制

- **圆环的平面限制**：切割平面必须垂直于环轴（归一化后 `|n·axis|` 在 8 ulp
  内为 1）或包含环轴（8 ulp 内为 0 且偏移在容差内）；偏移平行平面与倾斜平
  面是 `unsupported`，留给 M3c-3。torus/torus 与 torus/cylinder 配对同样在配对
  前 `unsupported`（圆环只支持平面切割）。
- **环面切链是弦逼近**：环面没有精确圆弧愈合，残差由 `max_cut_residual`
  报告，QA-14 要求 `<= 1e-3`；平面帽上的切圆仍解析愈合。
- **球、锥不支持**：分别是 cap 拓扑与闭环/顶点拓扑缺口，消息与零计数见
  ADR-0028 与架构 §16.3。
- **修剪结果不能网格化**：布尔输出的修剪面边界是非直边/含孔洞，`tessellate`
  按 ADR-0027 确定性拒绝；体积只能走 `detail::curved_solid_volume`。
- **分类网格弦高固定**：默认 1e-3，驱动无旋钮；基准数字只对应这一采样。
- **单线程单机**：Release `/O2`、单线程、单机单次测量，不与 M3b-2 的圆柱
  数字直接比较。

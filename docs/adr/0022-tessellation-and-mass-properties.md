# ADR 0022: 网格化边采样契约与质量属性积分

- 状态: 接受
- 日期: 2026-11-08
- 关联: 架构文档 §8.10、§8.11、§1.2、§16.2、§16.3；ADR-0021

## 背景

M2 交付 B-rep 网格化与质量属性，两者共享同一条几何边界：

- QA-10 要求 10 万面网格化**水密**——相邻面在共享边上的采样点必须逐点相同；
  弦高受 `deflection` 约束；三角形朝向与面 sense 一致、无零面积。
- QA-11 要求体积/质心/惯性矩相对误差 ≤ 1e-6。架构 §8.11 原本以「散度定理 +
  裁剪面 Gauss–Legendre，并与网格化结果交叉验证」为目标；但 M2 的消费方是
  解析基本体，裁剪与 SSI 尚未实现。

M2 还不能引入 OCCT 作为参考实现（计划约束：无新外部依赖），而 box/cylinder/
sphere/torus 的质量属性都有精确闭式解。

## 选项

1. **每面独立采样边**：实现简单；但两个面在共享边上各自采样，浮点求值可能
   产生不同点，水密只能靠焊接补救，QA-10 的「逐点一致」无法保证。
2. **边采样缓存 + 面复用**：每条边按 `deflection` 采样一次，所有使用该边的
   coedge 复用同一序列（按遍历方向取正序/逆序）；面三角化只消费缓存。
3. **质量属性走网格**：对三角网做散度求和；精度受 `deflection` 与三角形朝向
   影响，球形/圆环的体积误差约为表面积×弦高，1e-6 需要极细网格，代价高。
4. **质量属性走参数域解析积分**：平面面用精确多边形矩，解析曲面用 Gauss–
   Legendre；与网格化解耦，精度只受求积阶数与边界采样影响。

## 决策

- **边采样（选项 2）**：`detail::tessellate_sample_edge(brep, edge, deflection)`
  在边的参数域内产生一次采样序列（直线取两端点；圆按弦高公式
  `step = 2·acos(1 − d/r)` 取等角步长；闭边不重复终点）。面的每个 coedge
  复用该序列，`reversed` 时逆序读取。这样共享边的点坐标来自同一次求值，
  水密是构造性的，不依赖焊接容差。
- **平面面**：边界采样后投影到面平面做 2D 三角化；偏差由弦高与三角化共同
  约束。质量属性复用同一采样点做精确多边形矩（见下）。
- **解析曲面面**：按 `(u,v)` 参数网格三角化，u 为整周期，v 取曲面自然范围；
  每方向段数由弦高公式从曲率半径推出。仅支持圆柱/圆锥/球/圆环的未裁剪
  整矩形；边界结构不匹配时返回 `unsupported`，不猜测裁剪域。
- **质量属性（选项 4）**：单位密度散度定理
  - `V = (1/3) ∮ x·n dA`
  - `C = (1/(4V)) ∮ x (x·n) dA`
  - `I_O = ∮ [(|x|²δ − x⊗x)(x·n)/5] dA`，再平移
    `I_c = I_O − V(|c|²δ − c⊗c)`。
  平面面上 `x·n` 是常数 `d`（面平面到原点的有符号距离，`reversed` 取负），
  积分退化为多边形面积矩：`A`、`∫x dA`、`∫x⊗x dA` 用鞋带公式精确计算，内环
  按存储的反向绕序自然取负。曲面面对 `(u,v)` 矩形做 `order×order`
  Gauss–Legendre（节点/权重运行时由 Newton 法求 Legendre 根得到，默认
  24 阶），`dA_vec = cross(du,dv) dudv`，求积点处累加上述三个积分。
- **QA-11 oracle（替代 OCCT）**：用闭式解作为参考：box `m/12(b²+c²)`，
  cylinder `m(3r²+h²)/12` 与 `mr²/2`，sphere `2mr²/5`，torus
  `m(R²+3r²/4)` 与 `m(R²/2+5r²/8)`。理由：M2 没有 OCCT 依赖，闭式解对基本体
  是精确的，误差直接反映实现而非参考模型；§1.2 的 OCCT 对比留给具备 B-rep
  布尔/裁剪能力的后续里程碑。

## 后果

- 正面：水密是边采样复用的结构性结果，QA-10 的水密检查在全部运行中通过；
  QA-11 最大相对误差 **7.62e-10**（门禁 1e-6），其中球/圆环达 1e-15 量级。
  质量属性不依赖网格分辨率，测试运行时间可控（质量属性用例 12 例）。
- 负面：平面面上的圆边按内接折线近似，圆柱端盖体积误差约
  `4·deflection/(9r)`（默认 1e-9 时实测 4.4e-10）；要更精确需减小
  `sampling_deflection` 或改用精确圆积分，M2 选择前者。
- 已知限制：曲面面只支持未裁剪整矩形，裁剪面返回 `unsupported`；网格化只
  覆盖解析面，NURBS/Bézier 返回 `unsupported`；QA-10 吞吐 0.20 Mtri/s
  未达 1.0 Mtri/s 门禁（见 `docs/benchmarks/m2.md`）。
- 跟进：M3 引入 SSI/裁剪后，把质量属性扩展到裁剪面（参数域 2D 布尔 + 分片
  求积）；网格化补 NURBS 与自适应细分；QA-10 在 CI 硬件复测或优化后重新判定，
  不得静默修改门禁。

# ADR 0024: M3b-1 的细分 + Newton SSI

- Status: Accepted
- Date: 2026-11-11
- Related: architecture §4.7、§8.6、§12.7、§16.2 M3、§16.3；M3b SSI 计划 Task 1–Task 10；ADR-0015、ADR-0023

## 背景

M3b 需要曲面-曲面求交（SSI）作为曲面布尔与 pcurve 生成的输入。M3a 的平面优先布尔
只处理平面面，交线是直线段；曲面面被 `unsupported` 拒绝。M3b-1 必须先交付一个可独立
验收的 SSI 组件：输入是未修剪的参数补丁，输出是有序交线折线，相切/重合/退化/不收敛
必须返回可诊断的失败，而不是空集或拓扑错误的曲线。

架构与 ADR-0015 已明确不做全局精确有理 SSI：解析曲面（Plane/Cylinder/Cone/Sphere/
Torus）与 NURBS 的统一精确有理表示会把次数推到不可控，且与现有 `SurfaceGeometry`
变体、`Pcurve2d`（仅直线段）的存储不匹配。M3b-1 因此只承诺**带显式容差的数值交线**，
正确性由每段残差 ≤ `tolerance` 定义，退化由诊断码定义。

## 选项

1. **全局精确有理 SSI.** 把所有曲面升为有理多项式并做符号消元。拓扑精确，但次数爆炸、
   NURBS 裁剪不可控，且与现有存储和容差模型不兼容；ADR-0015 已排除。
2. **逐曲面对解析公式.** 为 15 种曲面组合分别推导闭式交线（圆、二次曲线等）。对
   解析-解析对可行，但对 NURBS、一般位置与相切退化没有统一路径，代码量随组合数
   平方增长，且无法复用到 M3b-2 的面级裁剪。
3. **自适应细分 + 三角-三角种子 + 四参数 Newton + 追踪.** 两个补丁各自自适应三角化，
   AABB 宽相筛出三角形对，三角-三角求交得到种子线段，用 4 参数 Newton 把端点精化到
   两张曲面上，再沿交线切向预测-校正追踪，端点聚类后按参数域边界或闭合条件收尾。
   精度由 `tolerance` 控制，退化由前置谓词诊断。
4. **纯网格布尔.** 直接把两个实体网格化后做网格布尔。实现简单，但丢失 B-rep 身份、
   pcurve 与容差语义，不能满足 M3b-2 的面级裁剪。

## 决策

M3b-1 采用选项 3。交付物是 header-only 的 `geom/brep/ssi.hpp` 与
`detail/ssi_surface.hpp`、`ssi_patch.hpp`、`ssi_tri_tri.hpp`、`ssi_solver.hpp`；
入口 `ssi(a, b, options)` 的契约为：

- **输入**：两个未修剪的参数补丁 `SsiPatch{surface, u0, u1, v0, v1}`，参数域跨度
  ≤ 2π；周期轴按曲面周期折回。补丁 AABB 退化或非有限时返回 `degenerate_patch`。
- **横截输出**：有序折线，每段 `residual ≤ tolerance`，端点为精化后的公共点；
  曲线按首点、参数与段数排序，保证同一输入位级确定。
- **退化诊断**：重合 → `coincident`；相切 → `tangent_contact`；补丁退化 →
  `degenerate_patch`；种子不收敛或容差低于坐标分辨率 → `no_convergence`；段预算耗尽 →
  `numeric_failure`（`"ssi: segment budget exhausted"`）。诊断绝不静默返回空集：
  即使细分后没有任何段（例如切入深度低于三角化分辨率，或 NURBS 自身重合且无重合谓词），
  只要三角形对报告过接触，也返回 `no_convergence`（`"ssi: no intersection curve could be certified
  at this tolerance"`）而不是空结果。
- **相切/重合判定**：先比较 `SurfaceGeometry` 变体与载体（NURBS 没有重合谓词，自身重合靠空曲线诊断兜底，绝不返回空集），
  再在 9×9 参数网格上做有符号距离与法向对齐检查；相切另做 21×21 单侧符号测试，
  几何带为 `max(1e-12·(1+max|p|), 0.05·tolerance)`。
- **细分**：弦高容差 `max(1e-3·diagonal, 64·tolerance)`，自适应四叉树每格取 9 个
  采样点（中心、四边中点、四角）以捕捉鞍点；`max_depth ≥ 6` 是契约（种子聚类按每边
  至少 64 格设计），默认 12。不同深度的叶子不要求边共形，允许悬挂节点。
- **种子与追踪**：三角形对端点经 Newton 精化，3D 位置在
  `max(64·tolerance, 1e-9·max(diagonal))` 内且切向一致（|dot| ≥ 0.9）的种子并查集
  合并为一条曲线；步长从 `diagonal/64` 起、上限 `diagonal/8`，闭合要求精化顶点落在
  起点 `8·tolerance` 内，跨周期缝按模 2π 比较参数距离。走到参数域边界即停，精确
  边界求交与边拆分留给 M3b-2。
- **预算与计数**：`max_segments` 限制输出段数；`accepted_segments` 为输出段数，
  `rejected_segments = max(0, extracted - accepted)`（饱和差，追踪可能一段种子产生
  多段输出，故不是“未使用几何”的计数）。
- **容差下限**：`tolerance < 2·eps·max(1, max|corner|)` 时返回 `no_convergence`，
  因为该带低于坐标的算术分辨率，无法认证。
- **不做**：全局精确有理交线、多段 pcurve、曲面面分割与曲面布尔（M3b-2）、healing
  （M3b-3）。

## 后果

- 交线精度由采样与 Newton 共同决定：细分弦高是启发式，悬挂节点使相邻三角形不完全
  共形，交线折线的端点一致性依赖 Newton 与种子聚类，而不是网格拓扑。
- 最坏成本按 `4^max_depth` 增长；默认 12 是为鲁棒性留的预算，调用方可用
  `max_depth` 换取速度，但低于 6 会被拒绝。
- 相切判定有检测下限：比 `max(1e-12·(1+max|p|), 0.05·tolerance)` 更浅的“切入”按
  契约报 `tangent_contact`，不会被当作横截线输出。
- 两条分支间距小于种子聚类半径（约 0.007×较小补丁对角线）时可能被合并成一条曲线；
  该近相切情形由前置谓词诊断，是 M3b-1 的已知限制。
- 混合尺度下重复曲线的残差修正（同一几何交线由不同尺度补丁产生时的重复/精度问题）
  推迟到 M3b-2；M3b-1 只保证单次调用的残差与确定性。
- 每次 `ssi()` 都重新细分、重新播种、重新追踪，没有跨调用缓存。QA-9 基准实测
  单位球-平面 1000 次调用的中位数为 15.91 ms/对，远超 100 µs/对的目标；这是
  M3b-1 的已知性能缺口，按计划如实记 FAIL，不修改门禁。
- 曲面布尔仍不可用：`boolean_solid` 继续拒绝曲面面；多段 pcurve 与面级调用是
  M3b-2 的前置。

## 重新评估的触发条件

M3b-2 需要面级 pcurve 或多段 pcurve；曲面布尔需要精确边界/边拆分；QA-9 的
100 µs/对目标成为实际交付门槛；或出现必须用精确有理拓扑才能解决的相切/重合案例。

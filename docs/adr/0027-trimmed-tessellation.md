# ADR 0027: M3c-1 修剪解析面的网格化与质量属性

- Status: Accepted
- Date: 2026-11-13
- Related: architecture §8.10、§8.11、§16.3；M3c-1 plan Task 1–Task 5；ADR-0022、ADR-0025

## 背景

M3b-2 的曲面包尔把圆柱与平面修剪成带窗口的侧面：面仍是 `Cylinder3`，但边界
是度为 1 的 NURBS 多段线（曲线段被离散成弦），且窗口可跨 `u = 0` 缝合线。
M2 的 `tessellate()` 只处理完整解析面（整圆帽的圆柱带、完整球/环/锥）与平面
面；`mass_properties()` 只处理整矩形解析域。QA-13 要求这类修剪面也能给出
水密、有限、逐面分组的网格，并要求质量属性在文档精度内匹配解析值。

直接复用整面网格（例如圆柱的 cap-to-cap 四边形带）会把窗口覆盖掉：它只按
闭合帽圆计数，不检查额外的边界边；把两份网格按容差焊在一起又会把 T 型接缝
“藏”起来，而不是修好。修剪域的 uv 边界在圆柱参数化下正好是直边（圆弧 ->
`v = const`，裁剪壁 -> `u = const`），但窗口跨缝合线时环在 uv 里是一条被切开
的矩形边界，两侧边是同一组 3D 顶点。

## 选项

1. **扩展每个曲面的解析网格并裁剪。** 在已有的 cap-to-cap / 经纬网格上按修剪
   环裁剪。实现量大，而且裁剪必须重新采样边界，容易与相邻平面面的边界顶点
   不一致，产生细缝或重复边。
2. **uv 环投影 + 三角化 + 共享边界索引。** 用 `face_loops_uv` 取环，环上的
   每个点直接取相邻面也在用的边采样表（`tessellate_edge_positions`）中的池
   索引，再在 uv 里三角化；边界子段由扇出补回，保证两侧网格用同一组索引。
3. **两份网格生成后按容差焊点。** 实现最短，但会把 T 型接缝和真实细缝一起
   抹平，无法诊断，也违反“不要用容差合并隐藏接缝”的评审要求。
4. **修剪面留到 M3c-2，M3c-1 只做整面。** 无法满足 QA-13，也拿不到窗口夹具
   的水密与质量属性证据。

## 决策

采用选项 2，并把契约固定为：

- **边界来源。** `detail::tessellate_trimmed_face` 逐 loop/coedge 调用
  `tessellate_edge_positions`，按 `coedge.reversed` 反向，去重相邻重复后投影到
  uv（`face_uv_project`，`u` 按 `face_uv_unwrap` 展开，可超过 `2*pi`）。边界
  顶点就是相邻平面面使用的同一批池索引，不重新采样、不按容差合并。
- **环与域。** 每个环用精确 `ring_orientation2` 归一化（外环 CCW、孔 CW），
  必须恰好一个外环。直边域（圆柱带）按水平/垂直边分解成条带：帽圆行保持
  采样点，内部行加入条带列，两条裁剪壁各自用 `fan_wall` 保留自己的采样点，
  因此粗壁（1 段）与细壁（21 段）都能与邻居逐位焊接。
- **三角化。** 每个条带/多边形交给 `triangulate_trimmed_domain`（Task 1）与
  `triangulate_polygon2`；uv 共线的边界采样点会先被裁剪器去掉，网格化后再把
  这些点按顺序扇出回到边界三角形里，使每个共享子段都真实存在，而不是被弦
  替代。
- **细化。** 细化为**逐边自适应弦高**：对每条非边界边取弦中点并投影到曲面，
  弦高 `> 0.9*deflection` 时在中点处劈开（预算 `8*triangles + 64` 次劈分，
  总三角形 2,000,000 上限 -> `numeric_failure`）。这不是“每面统一 4^L 细分”：
  预算和 2e6 上限保证弦高网格即使不收敛也不会失控；实测 2e-3/1e-3/1e-4 的
  三角形数为 894/1268/3744。
- **错误契约。** 有 NURBS 多段线边界的修剪面只报修剪路径的错误（不再把
  “cylinder face is missing a cap circle” 透出）；孔洞（两个环）与斜切
  （椭圆 uv 边界）返回 `Errc::unsupported`“tessellate: trimmed face does not
  follow the surface”；纯直线/圆弧边界的非整面仍走解析路径的既有错误，保持
  覆盖测试不变。
- **质量属性。** 用同一份 uv 环与三角化（角点简化后 12 个三角形），在每个
  uv 三角形上按 7 点 Dunavant 在精确曲面上取 `eval/du/dv` 与面 Jacobian，
  体积/一阶矩/二阶矩沿用 `mass_add_surface_element` 的符号约定；步长
  `max(sqrt(8*curved_sampling_deflection), 5e-2 rad)`，默认
  `curved_sampling_deflection = 1e-5`。整面解析面继续走原矩形
  Gauss-Legendre 路径，逐位不变。
- **选项校验。** `curved_sampling_deflection` 非有限或 `<= 0` 返回
  `Errc::tolerance_violation`“mass_properties: options are out of range”。

## 后果

- **QA-13（实测）。** 60 度开窗圆柱（8 面/57 边/51 顶点）在
  `deflection = 2e-3` 下：水密（每条边 2 次使用）、449 个顶点全部有限、所有
  三角形索引 `< positions.size()`、`triangle_face` 长度等于三角形数、两次运行
  的 `positions` 逐字节一致（`memcmp`）、`triangles`/`triangle_face` 相等；
  单用例 7,621 条断言通过。全量 Debug 与 Release 各 891 个用例、657,790 条
  断言全绿，`/W4 /WX /utf-8` 零警告。
- **弦高与细化。** 侧面 uv 面积和 `11.519173063163` 对环面积
  `11.519173063162574`，最大 uv 跨度 `0.273182 < pi/2`，最大弦高偏差
  `0.009314 <= 1e-2`，内向三角形 0。网格体积相对误差：
  4.412e-3（1e-2）、9.327e-4（2e-3）、4.565e-4（1e-3）、4.641e-5（1e-4），
  与 `O(deflection)` 的弦高误差一致。
- **质量属性（实测）。** r=1 开窗圆柱：体积
  `5.826573827129446`（相对 `curved_solid_volume` 的 `5.826573829688656`
  误差 `4.392e-10`），质心 `(-0.057209149585, 0, 1)`，质心惯量
  `(3.592034030768, 3.356457963297, 2.835803705475)`，非对角 `< 1e-13`；
  r=10/h=5 缩放窗口：`1433.812883484877375`，误差 `4.379e-11`。步长下限使
  默认调用约 0.1 s/面，同时把大修剪面的可测精度限制在 ~1e-6。
- **规范面不变。** box/cylinder/torus 的网格哈希与 14a89df 前逐位一致
  （`2abc6bb21fd6d800` / `687a72048f8f4296` / `c808f6ee4d9c72db`）；
  质量属性也有逐位回归测试。修剪路径只在 `tessellate_face_has_polyline_edge`
  为真且解析域查找返回 `unsupported` 时启用。
- **已知限制（M3c-2）。** 孔洞修剪面（窗口不跨缝合线 -> 外环 + 孔）与斜切
  椭圆边界返回 `unsupported`；球/圆环/锥作为布尔操作数、度 >= 2 的 NURBS
  修剪轮廓同样延后；布尔在裁剪线附近留下 190 个同面 `7e-13` 擦边点（
  `1e-12` 绝对容差下 0 个 T 型接缝），属布尔采样精度而非网格化缺陷。
- **偏差。** 计划文本中的“每面统一 4^L 细化”与“质量属性 1e-5 相对精度”
  已在实现中替换为逐边自适应弦高与 `max(sqrt(8*defl), 5e-2 rad)` 步长下限；
  Task 2/3/4 报告与 `docs/benchmarks/m3c1.md` 记录了实测值与理由。
- **测试证据。** QA-13（`tests/unit/tessellate_trimmed_test.cpp`）、弦高/水密/
  朝向/细化/确定性用例，以及 r=1 与 r=10 的质量属性用例；复现命令与完整
  数字见 `docs/benchmarks/m3c1.md`。

## 重新评估的触发条件

M3c-2 加入球/圆环/锥操作数、NURBS 修剪轮廓或孔洞域（多环）时；出现需要
逐面统一细化或红绿一致的裂缝修复方案时；质量属性需要把大面精度推到 1e-6
以下（需要给边界采样也加下限）时。

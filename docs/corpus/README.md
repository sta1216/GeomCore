# 退化语料库约定

语料库根目录为 `tests/corpus/`（本文件位于 `docs/corpus/`，只记录约定）：

- `tests/corpus/degenerate/`：共线、重合边、共面、重复点、零面积、反向绕序、近退化、超大尺度比。
- `tests/corpus/cad/`：相切、重合面、共边、极点、细长面、容差链、多壳（M3 起填充）。
- 序列化格式与架构文档 §6.7 的 `GEOM` 二进制一致；每个文件附 `.sha256` 与一句话来源说明，删除需评审。
- 生成脚本随语料一并提交，保证可复现；任何 fuzz 崩溃必须最小化后加入对应目录，并在回归测试中引用。
